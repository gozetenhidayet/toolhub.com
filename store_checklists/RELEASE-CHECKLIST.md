# Release Checklist

1. Replace Google demo App IDs and banner ad unit IDs with your own AdMob IDs.
2. Keep demo/test ads during all development and internal testing.
3. Create Android and iOS apps in AdMob.
4. Create the UMP consent message in AdMob > Privacy & messaging.
5. Publish `https://toolnova.tools/app-ads.txt`.
6. Add `https://toolnova.tools/` as the developer website in both store listings.
7. Test every one of the 35 tools on small and large phones.
8. Verify downloads, file pickers, camera/gallery access and sharing.
9. Test offline and poor-network error states.
10. Run accessibility checks, screen-reader labels and dynamic text.
11. Generate Android App Bundle and signed iOS archive.
12. Submit truthful screenshots and descriptions; do not claim functions that are not working.
