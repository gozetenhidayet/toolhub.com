TOOLNOVA HIGH-ADVANCED TOOL WORKSPACE UPDATE
Date: 2026-08-14

WHAT CHANGED
- The existing homepage/body layout was preserved exactly. The new work is scoped to tool workspaces and tool-result UX.
- Every tool now opens inside a professional wide workspace with a category header, trust badges and 3-step workflow.
- Desktop gets a right productivity sidebar with privacy/workflow information and related tools.
- Phones/tablets use a true full-screen tool workspace with safe-area spacing.
- Upload areas now have a premium drag/drop design, file metadata and image thumbnails.
- Multi-file queues can be drag-reordered.
- Completed results receive a common action suite: Download, Rename, Copy, Share, Print, New task, plus suggested next tools.
- Document Scanner now exposes separate Camera and Choose Photos entry points with a professional settings panel.
- Image to PDF now includes page size, orientation, margin and image-fit options.

RESULT ACTION BEHAVIOR
- File-producing tools download the actual generated PDF/DOCX/XLSX/TXT when the result is available.
- Calculator/text results can also be downloaded as TXT, copied, shared or printed.
- Share uses the device Web Share API when supported and falls back gracefully.
- Rename downloads another copy with the user-selected filename while preserving the extension.
